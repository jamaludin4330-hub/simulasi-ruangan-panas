Struktur stock-flow

Persamaan model

C * dT/dt = Q_heater - UA * (T - T_luar)

dT/dt = (1/C) * [ Q_heater - UA * (T - T_luar) ]

Euler       : T[k+1] = T[k] + dt * dT/dt
Steady state: T_ss   = T_luar + Q_heater / UA
Konstanta   : tau    = C / UA
Analitik    : T(t)   = T_ss + (T0 - T_ss) * exp(-t / tau)

Asumsi

  • Suhu ruangan seragam di semua titik, sehingga model berupa ODE.
  • C dan UA konstan selama simulasi.
  • Tidak ada sumber panas lain (orang, peralatan, sinar matahari).
  • Euler stabil jika dt < 2 * tau.
